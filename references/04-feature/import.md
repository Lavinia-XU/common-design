# 导入功能点设计模板

## 适用场景
- 用于批量导入、模板下载、文件上传、导入进度反馈、冲突处理、导入结果查看等需求。
- 适用于用户、设备、资产、策略、对象组、标签、任务配置等具备批量数据录入诉求的页面。
- 主流程为批量导入配置、导入进度反馈与导入结果提示（成功、部分失败、全部失败）；仅当业务需求特别强调错误数据支持在线修正时，才将结果提示扩展为错误列表在线编辑形态。

## 推荐页面组合
| 页面ID | 页面名称 | 页面类型 | 页面用途 | 入口方式 | 关键交互 |
|---|---|---|---|---|---|
| import-config | 批量导入配置 | 表单弹窗 | 下载模板、上传数据并设置冲突处理规则 | 来源列表页点击“批量导入” | 下载模板、上传文件、选择冲突处理规则、开始导入 |
| import-progress | 正在导入 | 进度弹窗 | 展示文件导入进度 | import-config 点击“导入” | 展示文件名、进度条和百分比，完成后按结果分流 |
| import-success | 导入成功 | 结果弹窗 | 展示完全成功或仅存在冲突跳过记录的结果 | import-progress 导入完成 | 展示成功数和跳过数，支持下载冲突报告和关闭 |
| import-partial-result | 导入完成（部分失败） | 结果弹窗 | 汇总成功、失败与冲突跳过数量，并提供后续处理 | import-progress 导入完成且仍存在失败记录 | 下载报告、重新导入、关闭 |
| import-failed | 导入失败（全部失败） | 结果弹窗 | 展示全部失败的结果与失败原因 | import-progress 导入完成且全部失败 | 下载报告、重新导入 |
| import-error-list | 导入异常处理（可选扩展） | 列表弹窗 | 查看、修正或删除校验失败的数据行 | 仅业务需求特别强调在线编辑时，替代部分失败或全部失败结果提示 | 在线编辑错误字段、删除记录、下载错误报告、提交修正数据 |

## 推荐流程

导入流程分三个阶段：选择导入文件、导入中、导入结果。每个阶段由一个独立弹窗承载，按顺序打开，前一阶段弹窗关闭后打开下一阶段弹窗。

基础流程（默认）：

```text
来源列表页（点击"批量导入"按钮）
  ↓ 打开弹窗
阶段1 选择导入文件：批量导入配置弹窗（import-config，表单弹窗）
  ↓ 点击"导入"提交文件，本弹窗关闭
阶段2 导入中：正在导入弹窗（import-progress，进度弹窗）
  ↓ 导入完成，本弹窗关闭，按结果分流打开对应的结果弹窗
阶段3 导入结果：以下三个结果弹窗就是导入结果阶段的容器
  ├─ 导入成功弹窗（import-success，结果弹窗）：全部成功或仅有冲突跳过时打开
  ├─ 导入完成弹窗（import-partial-result，结果弹窗）：仍有失败记录时打开
  └─ 导入失败弹窗（import-failed，结果弹窗）：全部失败时打开
```

各阶段容器展示的信息：
- 批量导入配置弹窗（import-config）：下载模板、上传模板、选择冲突处理规则；点击"导入"提交文件后关闭本弹窗，进入导入中。
- 正在导入弹窗（import-progress）：文件名、进度条与百分比；导入完成时关闭本弹窗，按导入数据情况打开对应的结果弹窗。
- 导入成功弹窗（import-success）：展示成功数与跳过数，支持下载冲突报告、关闭；"导入成功"提示出现即代表导入结果阶段，关闭后返回来源列表页。
- 导入完成弹窗（import-partial-result）：展示成功、失败与冲突跳过数量汇总，支持下载报告、重新导入、关闭。
- 导入失败弹窗（import-failed）：展示失败数量与失败原因，支持下载报告、重新导入。

在线编辑扩展流程（仅当业务需求明确要求错误数据支持在线修正时启用）。与基础流程的区别：阶段3 变为错误数据处理，共三个阶段，没有独立的结果阶段；全部成功后直接打开导入成功弹窗展示导入结果：

```text
来源列表页（点击"批量导入"按钮）
  ↓ 打开弹窗
阶段1 选择导入文件：批量导入配置弹窗（import-config，表单弹窗）
  ↓ 点击"导入"提交文件，本弹窗关闭
阶段2 导入中：正在导入弹窗（import-progress，进度弹窗）
  ↓ 导入完成且存在失败记录，本弹窗关闭，不打开任何结果弹窗，直接打开在线编辑弹窗
阶段3 错误数据处理：导入异常处理弹窗（import-error-list，列表弹窗）
  ↓ 提交修正数据后再次校验
  ├─ 仍存在失败记录：留在本弹窗，刷新展示剩余错误记录，继续编辑，重复本阶段直到无失败记录
  └─ 全部成功：本弹窗关闭，打开导入成功弹窗（import-success，结果弹窗）展示导入结果
```

在线编辑流程的容器说明：
- 导入异常处理弹窗（import-error-list，列表弹窗）展示校验失败的记录列表，支持在线编辑错误字段、删除记录、下载错误报告、提交修正数据；提交后重新校验，有错误留在本弹窗继续编辑，直到全部成功。
- 该模式下部分失败与全部失败的结果弹窗（import-partial-result、import-failed）不出现，由本弹窗替代；导入成功弹窗（import-success）仍保留，作为全部成功后的最终结果提示。

- 弹窗内组合：时间轴、上传、表单片段与底部按钮在 `IxModal` 内容区内组合；底部操作按钮使用 `IxButton`，确定为主按钮、取消为次按钮。

## 页面设计要点

### 1. 下载模板/上传文件
- 页面名称：批量导入配置。
- 页面ID：`import-config`。
- 页面类型：表单弹窗。
- 页面用途：用户通过下载并填写 Excel 模板，批量导入业务数据；可指定导入数据与已有数据冲突时的处理方式。
- 页面入口：来源列表页点击“批量导入”入口。

#### 页面内容
- 导入阶段区使用右侧时间轴（`IxTimeline`）展示三个阶段，顺序为下载模板、上传模板、导入规则；轴线位于内容区右侧，节点内容显示在轴线左侧，节点之间以轴线连接，不使用步骤条，也不使用横向分割线。
- 下载模板：
  - 提示文案：“还没有导入模板？先点击下载并填写对应的信息”。
  - “下载模板”按钮用于获取导入 Excel 模板。
- 上传模板：
  - 提示文案：“将您填好信息的文件上传于此，支持.xls、.xlsx格式，不可超过1MB”。
  - “上传模板”按钮用于选择本地文件。
  - 上传完成后展示文件名、上传进度，以及移除文件的关闭入口。
- 导入规则：
  - 提示文案：“当导入数据和已有数据存在冲突时：”。
  - 单选项“跳过”：默认选中，保留已有数据，不导入冲突记录。
  - 单选项“替换”：以导入文件中的记录覆盖已有冲突数据。
- 底部操作：
  - “确定”：校验文件后启动导入任务。
  - “取消”：关闭弹窗并放弃本次配置。
  - 关闭图标：关闭弹窗。

#### 关键交互
- 用户应先下载模板、按字段规范填写后再上传。
- 上传文件仅允许 `.xls`、`.xlsx` 格式，大小不得超过 1MB。
- 文件上传完成后，需要展示文件名称、上传进度和移除入口，便于用户确认或重新选择文件。
- 点击“确定”后进入 `import-progress`。
- 冲突记录是否跳过或替换，取决于用户在导入规则中选择的处理方式。

### 2. 上传中
- 页面名称：正在导入。
- 页面ID：`import-progress`。
- 页面类型：进度弹窗。
- 页面用途：在后台解析并写入上传文件时，向用户反馈当前处理的文件及实时进度。
- 页面入口：批量导入配置页点击“确定”。

#### 页面内容
- 标题展示“正在导入”。
- 展示 Excel 文件图标。
- 展示当前导入的文件名称。
- 展示进度条与百分比，例如 `50%`。

#### 关键交互
- 导入期间，背景中的配置弹窗保持不可操作状态，避免用户重复提交或修改导入配置。
- 进度完成后，按导入结果进入主流程的结果提示：
  - 全部记录成功，或失败记录为零、仅存在冲突跳过记录时，进入 `import-success`。
  - 存在失败记录时，进入 `import-partial-result`。
  - 文件格式校验失败或文件解析失败，全部记录未导入时，进入 `import-failed`。
- 可选扩展：仅当业务需求特别强调错误信息支持在线编辑时，`import-partial-result` 与 `import-failed` 替换为 `import-error-list`，进入“可选扩展：错误信息在线编辑后提交”所述形态。

## 导入结果提示（主流程）{#import-result-wireframe}

本锚点覆盖以下三种结果变体的线框图。

主流程包含以下三种结果状态，默认均为纯结果提示形态，不提供弹窗内编辑；仅当业务需求特别强调错误信息支持在线编辑时，部分失败与全部失败替换为“可选扩展：错误信息在线编辑后提交”所述形态。

### 导入成功
- 页面ID：`import-success`。

线框图：

```text
┌──────────────────────────────────────────┐
│ 导入成功                               × │
├──────────────────────────────────────────┤
│                                          │
│              ✓（成功图标）               │
│                                          │
│                导入成功                  │
│  23 条成功，1 条数据因与原信息冲突跳过    │
│                                          │
│                                          │
│         [下载冲突报告]   [关闭]          │
│                                          │
└──────────────────────────────────────────┘
```

#### 组件信息

- 弹窗：使用 `IxModal`（success 能力或结果弹窗形态），展示成功图标、标题与结果文案。
- 按钮："下载冲突报告"、"关闭"均使用 `IxButton` 普通按钮，同一行排列、居中对齐，位于结果文案下方；弹窗右上角为关闭图标。

- 展示成功图标与标题“导入成功”。
- 结果文案采用“XX 条成功，X 条数据因与原信息冲突跳过”的格式，包含成功导入的数据条数，以及因与原有信息冲突、按“跳过”规则未导入的数据条数。
- 支持“下载冲突报告”，报告应包含冲突记录及其冲突原因或冲突字段。
- 支持“关闭”和关闭图标，关闭后返回来源列表页。

### 导入完成（部分失败）
- 页面ID：`import-partial-result`。

线框图：

```text
┌──────────────────────────────────────────────────────┐
│ 导入完毕                                          ×  │
├──────────────────────────────────────────────────────┤
│                                                      │
│              ⚠（警告图标）                           │
│                                                      │
│                导入完毕                              │
│  20 条成功，2 条失败，1 条数据因与原信息冲突跳过      │
│        （其中"2 条失败"红色醒目提示）                │
│                                                      │
│                                                      │
│         [下载冲突报告]   [重新导入]                  │
│                                                      │
└──────────────────────────────────────────────────────┘
```

#### 组件信息

- 弹窗：使用 `IxModal`（warning 能力或结果弹窗形态），展示警告图标、标题与结果文案，结果文案中失败部分使用红色醒目提示。
- 按钮："下载冲突报告"为主按钮（`IxButton` mode="primary"），"重新导入"为普通按钮，同一行排列、居中对齐，位于结果文案下方；弹窗右上角为关闭图标。

- 展示警告图标与标题“导入完毕”。
- 结果文案采用“XX 条成功，X 条失败，X 条数据因与原信息冲突跳过”的格式，包含成功导入的数据条数、失败数据条数、因与原信息冲突跳过的数据条数。
- “X 条失败”部分使用红色醒目提示。
- 支持“下载冲突报告”或未成功处理数据报告；实际报告范围需明确是否同时包含失败与冲突跳过记录。
- 支持“重新导入”，返回 `import-config`，允许重新下载模板、修改数据文件并再次上传。
- 存在未解决失败记录时，不应展示为完全成功状态。
- 重新导入应开启新的导入任务，不应重复写入本次已成功导入的数据。
- 本状态默认为纯结果提示形态；仅当业务需求特别强调错误信息支持在线编辑时，替换为 `import-error-list` 在线编辑弹窗。

#### 组件信息

- 按钮：“下载冲突报告”为主按钮（`IxButton` mode="primary"），“重新导入”为普通按钮，同一行排列、居中对齐，位于结果文案下方；弹窗右上角为关闭图标。

- 重新导入应开启新的导入任务，不应重复写入任何已导入数据。

## 可选扩展：错误信息在线编辑后提交{#import-error-list-wireframe}

仅当业务需求特别强调错误信息支持在线编辑时启用本形态；启用后，导入结果提示中的“导入完成（部分失败）”与“导入失败（全部失败）”替换为本弹窗，主流程其余页面不变。

- 页面名称：导入异常处理。
- 页面ID：`import-error-list`。
- 页面类型：列表弹窗。
- 页面用途：展示导入校验失败的数据，支持用户在线修正错误字段、删除无效数据后再次提交。
- 页面入口：导入完成后存在校验失败记录，且业务需求明确要求在线编辑时，由部分失败或全部失败结果提示切换进入。

#### 组件信息

- 弹窗：使用 `IxModal`，承载导入结果摘要与错误列表。
- 表格：使用 `IxProTable`，其中性别列单元格内嵌 `IxSelect` 下拉修正，工号、手机号、邮箱、直属上级工号使用 `IxInput` 行内编辑；校验异常的输入框使用错误状态样式。
- 刷新：表格右上角使用 `IxButton` icon 按钮承载刷新入口。
- 按钮：底部"提交"为主按钮、"取消"为普通按钮，使用 `IxButton`，遵循主操作在前规则。

#### 页面内容
- 导入结果摘要：
  - 展示警告图标和标题“导入完毕”。
  - 汇总成功导入数量、失败数量、因与原信息冲突而跳过的数量。
  - 失败数字使用醒目提示。
  - 提供“下载错误报告”按钮，用于下载失败记录及错误原因。
- 错误列表：
  - 标题为“错误列表”。
  - 通过表格展示失败的导入数据。
  - 可展示字段包括姓名、性别、工号、手机号、邮箱、工作地、直属上级工号和操作。
  - 性别可通过下拉选择修正。
  - 工号、手机号、邮箱、直属上级工号可直接编辑。
  - 操作列提供“删除”，用于从本次待提交数据中移除该记录。
  - 存在校验异常的输入框以错误状态标识，用户需要修正字段内容后重新提交。
  - 表格右上角提供刷新入口，用于重新加载或恢复错误数据列表。
- 底部操作：
  - “提交”：提交修正后的失败记录。
  - “取消”：放弃本次错误修正并关闭弹窗。
  - 关闭图标：关闭弹窗。

#### 关键交互
- 导入后端需对每行进行字段格式、必填项及业务关联关系校验。
- 用户可直接修改存在错误提示的字段；修改后应重新校验。
- 用户也可删除无法修正或无需导入的错误行。
- 删除记录前需弹出确认提示：“确认删除该记录吗？”。
  - 点击“确定”：删除该条错误记录。
  - 点击“取消”：保留该记录。
- 点击“提交”后，仅提交修正后保留的失败记录，不重复处理已成功或已跳过的数据。
- 再次提交完成后，根据校验结果进入：
  - 全部成功：本弹窗关闭，打开 `import-success` 展示导入结果。
  - 仍存在失败记录：留在本弹窗，刷新展示剩余错误记录，继续编辑，重复本阶段直到无失败记录。

## Coding提示
- 推荐复用组件：弹窗表单、阶段时间轴、文件上传、单选规则、进度弹窗、结果反馈、可编辑表格（仅在线编辑扩展场景使用）、表单校验、二次确认。
- Mock数据要求：主流程覆盖上传前、上传完成、导入中、全部成功、仅冲突跳过、部分失败、全部失败（文件格式有误）、报告下载失败等状态；可选扩展场景补充在线修正后成功、在线修正后仍部分失败、删除错误行。
- 校验规则：覆盖文件格式、文件大小、必填项、字段格式、业务关联关系、冲突记录处理规则。
- 状态联动：导入成功后刷新来源列表页；提交修正数据时只处理保留的失败记录，不重复写入已成功或已跳过数据（仅在线编辑扩展场景）。
- 极端情况：重复点击导入、导入过程中关闭、文件上传后移除、错误列表为空、全部错误行被删除、报告下载失败、网络异常、模板版本不匹配。
