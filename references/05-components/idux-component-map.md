# idux 组件映射

## 文档目的

本文件定义 Common Design 中页面语义到 idux 标准组件与样式变体编号的映射，用于在设计阶段准确识别下游应使用的组件与样式；组件 Props 配置、事件绑定、数据同步等编码规则由下游编码 Skill 承载。

本文件只定义：

- 页面语义对应的首选组件；
- Coding 时命中组件的触发条件与选型边界；
- 设计稿样式变体的编号。

本文件不负责判断：

- 当前产品是否已有业务封装组件；
- 是否应复用已有页面或业务模块；
- 当前代码仓库中具体组件路径、版本或完整 API；
- 组件 Props 配置、事件绑定与数据处理的编码实现；
- 页面最终采用直接引用、组件复用、复用框架还是全新开发。

上述内容由 `prd-design-code` 结合 Product Design 和当前代码环境决定。

## 使用说明

- 本表仅负责设计阶段识别：把页面语义与设计稿样式识别为应使用的组件与样式变体编号，不承载编码规则。
- 表内“适用场景”均表示触发条件：页面描述或设计说明出现相应结构时，应命中对应组件；场景句尾的选型边界用于区分易混组件。
- 表内“组件名称”代表组件的基础形态：适用场景命中组件时默认使用基础形态，如常规文本输入直接使用 `IxInput`。
- 表内“样式变体编号”仅对应特定样式变体，不替代组件基础形态：设计说明出现编号时按编号对应样式实现，未出现编号时不套用编号形态、样式以组件基础形态为准，如仅密码输入场景才使用 `IxForm_Password`；未列出变体编号的组件样式一律以组件基础形态为准；编号以设计规范为准，不得引入表外编号或自创变体名。

## 组件映射表

| 设计语义 | 组件名称 | 适用场景 | 样式变体编号 |
|---|---|---|---|
| 按钮 | `IxButton` | 页面描述中出现新增、保存、取消、查询、重置、导入、导出、删除、确认等可点击操作时，统一使用。同一组操作中主操作唯一。 | — |
| 弹窗/对话框 | `IxModal` | 页面需要展示确认、提示、告警、结果反馈，或承载非表单型的轻量内容浮层时使用。完整新增编辑表单优先使用 `IxProFormModal`，复杂多步骤流程不塞入普通弹窗。 | `IxModal_Type_Confirm`（提示弹窗-确定）、`IxModal_Type_Info`（提示弹窗-通知）、`IxModal_Type_Success`（提示弹窗-成功）、`IxModal_Type_Warning`（提示弹窗-警告）、`IxModal_Type_Error`（提示弹窗-错误） |
| 抽屉 | `IxDrawer` | 页面要求在保留当前页面上下文的前提下打开详情、辅助配置或轻量编辑面板时使用。表单默认使用弹窗承载，抽屉表单仅在业务设计特别说明时使用；抽屉嵌套最多两层。 | — |
| 标签页 | `IxTabs` | 页面描述中出现视图切换、同层级内容切换或通过选项卡切换筛选维度时使用。导航型标签页使用下划线编号，筛选型标签页使用分段型编号。 | `IxTabs_CardType`（卡片型）、`IxTabs_LineType`（下划线）、`IxTabs_SegmentType`（分段型-轻量）、`IxTabs_SegmentType_Primary`（分段型-深色） |
| 标签 | `IxTag` / `IxTagGroup` | 表格、详情、列表或表单回显中需要展示分类、状态、属性标记、等级标识、可移除条目或多个关联标签时使用。可变更标签仅用于低风险、可逆的标记切换；多个关联标签由 `IxTagGroup` 管理。 | `IxTag_Basic`（浅色标签）、`IxTag_Filled`（深色标签）、`IxTag_Icon_Status`（icon文字标签）、`IxTag_Icon`（icon色块标签）、`IxTag_Dot`（点状标签）、`IxTag_Editable`（可变更标签）、`IxTag_Closable`（可编辑标签）、`IxTag_GroupedTag`（组合标签） |
| 徽标数 | `IxBadge` | 按钮、图标、文字旁需要展示数字或状态标记，或消息提醒、未读数量、告警计数等场景时使用。表达“当前为 0 条”与“无数据”的差异需在设计说明中明确。 | — |
| 文本 | `IxText` | 定宽区域内展示可能溢出的名称、地址、规则、说明或多行文本，或需要提供纯文本复制能力时使用。截断文本必须提供查看完整内容的方式。 | — |
| 单选框 | `IxRadio` / `IxRadioGroup` | 表单或筛选条件中出现一组选项互斥选择，如状态、动作、模式、类型等单选值时使用。 | `IxRadio_Fieldset`（基础组合控件）、`IxRadio_Basic`（基础单选）、`IxRadioGroup_DataSource`（基础按钮） |
| 选择器 | `IxSelect` | 表单、搜索或筛选中需要从候选项选择单个或多个值，或需要允许用户自由输入并回填为选项时使用。 | `IxSelect_Group`（分组下拉面板）、`IxSelect_ExpandableGroup`（可展开分组）、`IxSelect_Searchable`（悬浮窗搜索）、`IxSelect_OverlayWidthAdd`（下拉带新增）、`IxSelect_SelectAll`（带全选） |
| 级联选择 | `IxCascader` | 数据集合具有清晰的层级结构，且必须逐级选择到末级（如组织、区域、分类、策略对象层级）时使用。 | `IxCascader_ChinaRegions`（国家/地区级联面板） |
| 树选择 | `IxTreeSelect` | 表单、筛选或权限配置中需要从带层级的数据中选择单个或多个节点，且父子节点可独立选中（如组织、设备组、资源目录、权限树）时使用。必须逐级选择到末级的层级选择应使用 `IxCascader`，表单内树选择不使用 `IxProTree`。 | — |
| 分页 | `IxPagination` | 数据列表、表格或可分页的搜索结果需要切换页码、页大小或定位当前页时使用。 | — |
| 统计数字 | `IxStatistic` | 概览统计区、Dashboard 或详情汇总区需要突出展示单一总量指标数值时使用，是概览纯数字统计与数字与子项统计卡片的数值承载组件。 | — |
| 饼图 | `IxPieChart` | 概览统计区或 Dashboard 需要展示互斥状态的占比分布时使用，如运行状态分布。状态数超过 5 个或非互斥拆分不使用饼图。 | — |
| 柱状图 | `IxBarChart` | 需要按分类对比数量或展示 TopN 排行时使用，如 Top5 风险用户。横向条形为概览 TopN 卡片的默认形态。 | — |
| 折线图 | `IxLineChart` | 需要展示指标随时间变化的趋势时使用，如近 7 天告警数量趋势。仅表达趋势，精确读数诉求与统计数字组合使用。 | — |
| 进度条 | `IxProgress` | 表格、卡片、任务详情或上传流程中需要展示完成率、使用率、容量占比、任务进度或异常进度状态时使用。 | — |
| 加载中 | `IxSpin` | 查询、提交、局部操作处理中，需要展示加载状态或阻止重复操作时使用。预计短耗时操作不使用加载态。 | — |
| 骨架屏 | `IxSkeleton` | 页面、详情、弹窗或模块首次加载时，需要以占位结构降低等待焦虑时使用。局部刷新不使用整页骨架。 | — |
| 空状态 | `IxEmpty` | 列表、表格、筛选、搜索、树或详情内容为空时使用。空状态必须提供下一步出口；无权限导致的空态不得渲染为创建引导。 | — |
| 结果页 | `IxResult` | 整页错误、无权限、操作完成或流程结束需要结果反馈时使用。局部错误不升级为整页结果页。 | — |
| 警告提示 | `IxAlert` | 局部模块错误、告警、提示信息需要内嵌持久展示时使用。需要持久展示的局部提示不使用即时提示；页面顶部提示条使用 Banner 系列编号，局部模块提示条使用 Part 系列编号。 | `IxAlert_Banner`（顶部提示条-警告色）、`IxAlert_Banner_Offline`（顶部提示条-灰色）、`IxAlert_Part`（局部提示条-警告色）、`IxAlert_Part_Offline`（局部提示条-灰色） |
| 即时提示 | `IxMessage` | 单次操作成功、失败或轻量反馈需要即时提示时使用。需要持久展示或批量通知时改用 `IxNotification`。 | — |
| 通知提示 | `IxNotification` | 需要持久展示或批量通知、告警、任务结果提醒时使用。需要用户处理的持久通知不使用即时提示。 | — |
| 文字提示 | `IxTooltip` | 图标、按钮、标签或文字需要悬停补充说明、解释禁用原因或展示完整内容时使用。长内容或需要交互操作时改用 `IxPopover`。 | — |
| 气泡卡片 | `IxPopover` | 点击或鼠标移入对象后，需要展示气泡式卡片浮层，用于进一步描述对象或执行相关操作时使用。复杂表单流程不塞入气泡卡片。 | — |
| 气泡确认框 | `IxPopconfirm` | 删除、停用、移除、重置等轻量确认操作需要在当前点击元素附近完成二次确认时使用。轻量确认不打开完整弹窗，复杂多步骤流程不塞入气泡确认框。 | `IxPopconfirm_Basic`（基本气泡窗）、`IxPopconfirm_Content`（气泡窗表单） |
| 步骤条 | `IxStepper` | 页面描述中出现明确的多步骤配置、逐步填写、进度导航或流程状态展示时使用。需要分步表单的校验、暂存与提交时优先使用 `IxProFormStepper`。 | — |
| 时间轴 | `IxTimeline` | 需要将信息以时间先后顺序串联展示，如操作记录、审计日志、任务流转、事件历史等时间流场景时使用。 | `IxTimeline_Left`（左侧时间轴）、`IxTimeline_LeftCard`（左侧时间轴-卡片）、`IxTimeline_Right`（右侧时间轴）、`IxTimeline_RightCard`（右侧时间轴-卡片） |
| 复选框 | `IxCheckbox` | 页面要求多项选择、布尔开关式确认、表格批量选择或全选/反选时使用。 | `IxCheckbox_Basic`（基本复选框）、`IxCheckbox_Button`（复选按钮）、`IxCheckbox_Fieldset`（复选组合控件） |
| 开关 | `IxSwitch` | 表单或行内需要二元开关式切换且切换即时生效时使用，如启用/禁用、开启/关闭、是否默认。高风险、不可逆操作不使用开关，改用需二次确认的按钮或气泡确认框。 | — |
| 日期选择 | `IxDatePicker` | 表单或筛选条件需要输入单个日期、日期时间或日期范围时使用。 | `IxDatePicker_Basic`（单个日期）、`IxDatePicker_Range`（日期范围）、`IxDatePicker_Shortcuts`（日期快捷选择） |
| 时间选择 | `IxTimePicker` | 表单或筛选条件需要输入单个时间点或时间范围，如执行时间、生效时间、营业时间、排班时间、开始与结束时刻等场景时使用。 | — |
| 颜色选择器 | `IxColorPicker` | 表单或配置项需要选择颜色值，如背景颜色、按钮颜色、主题色、状态色等场景时使用。 | — |
| 表单 | `IxProForm` | 页面、弹窗或抽屉中存在多个字段录入、校验、重置和提交的统一流程时默认使用。弹窗表单使用 `IxProFormModal`，抽屉表单使用 `IxProFormDrawer`，不降级为基础表单手工组合。 | — |
| 基础输入框 | `IxInput` | 表单字段、搜索栏或独立筛选条件需要输入单行文本、名称、地址、关键字等值时使用。 | `IxForm_Password`（密码输入框带校验）、`IxForm_InternationalTelePhone`（国际电话号码）、`IxInput_Addon_Before`（前置输入框）、`IxInput_Addon_After`（后置输入框）、`IxInput_Addon`（前后置输入框） |
| 数字输入框 | `IxInputNumber` | 表单字段或筛选条件需要录入数量、端口、阈值、优先级数值、时长或比例等数值时使用。需要数值约束的字段不使用文本输入框。 | — |
| 文本域输入框 | `IxTextarea` | 需要输入多行纯文本信息（如备注、描述、说明）时使用，是最基础的纯文本多行输入，内容按整体处理。纯文本多行场景不误用 `IxProTextarea` 或富文本编辑。 | — |
| 高级文本域/行号输入框 | `IxProTextarea` | 表单需要输入多行文本、脚本片段、规则表达式、名单、多个 IP 地址、JSON、备注或其他需要行号与逐行校验的内容时使用；与 `IxTextarea` 的区别是支持更复杂的格式、可在输入框内显示行号、针对每行内容进行格式校验和报错。富文本编辑场景不误用本组件。 | — |
| 上传 | `IxUpload` | 表单或业务场景需要将文件从本地即时上传至远程系统，如图片、附件、模板文件、图标等场景时使用。上传触发方式、文件格式与大小限制需在设计说明中明确。 | — |
| 表格 | `IxProTable` | 页面描述中出现同类对象列表、字段列、行操作、分页、批量操作或管理型数据视图时默认使用。单对象详情使用 `IxProDesc` 不使用表格；筛选项超过 4 个时搭配 `IxProSearch`；状态字段使用 `IxTag` 等状态组件展示。 | — |
| 基础表格 | `IxTable` | 轻量数据展示、小数据量列表或需自定义行渲染的表格场景使用；不具备服务端分页、筛选与列配置能力，完整管理型列表优先使用 `IxProTable`。状态字段列使用 `IxTag` 展示。 | `IxTable_Basic`（基础表格）、`IxTable_Expandable`（可展开表格）、`IxTable_GroupedTable`（分组表格）、`IxTable_NestedTable`（嵌套子表格） |
| 高级搜索 | `IxProSearch` | 单页存在超过 4 个筛选字段，或需要筛选字段选择、条件联动、常用条件收藏等能力时使用。筛选项不超过 4 个时平铺普通控件即可。 | — |
| 描述列表 | `IxProDesc` | 详情页、抽屉详情、日志详情或只读字段展示需要按“字段名-字段值”呈现时使用。以字段名-字段值为主的详情不使用表格替代。 | — |
| 表单弹窗 | `IxProFormModal` | 新增、编辑、复制、配置等需要在弹窗内完成字段加载、录入、校验与提交的表单时默认使用。改用 `IxProFormDrawer` 仅限用户额外说明或业务设计特别说明的场景。 | — |
| 表单抽屉 | `IxProFormDrawer` | 默认不使用；仅在用户额外说明或业务设计特别说明时，用于需要保留列表或详情上下文、且字段量或分组复杂度较高的新增、编辑、配置、关联类表单。 | — |
| 分步表单 | `IxProFormStepper` | 多个字段组存在先后依赖，且需要逐步校验、暂存、回退与最终确认提交时使用。无步骤依赖的普通表单不拆分步。 | — |
| 动态表单列表 | `IxProFormList` | 表单内需要动态新增、删除、排序或批量配置同结构字段组，如规则条件、关联对象、参数组或通知接收人时使用。 | — |
| 穿梭框 | `IxTransfer` | 需要通过穿梭面板在候选选项与已选选项之间左右移动维护选中项时使用，适用于结构简单、候选量小的穿梭选择。数据量大、需要搜索筛选或树结构的复杂穿梭选择使用 `IxProTransfer`。 | `IxTransfer_Basic`（基础穿梭框） |
| 高级穿梭框 | `IxProTransfer` | 页面或表单需要从大量候选对象中搜索、批量选择并维护已选对象，如用户、资产、策略对象或权限项时使用。少量简单选项的单选或多选不使用穿梭框。 | — |
| 高级树型控件/左树 | `IxProTree` | 页面需要展示多级分类、组织、目录、资产层级，或左侧树与右侧表格/详情联动时使用。少量扁平分类不渲染为树。 | — |
