# idux 组件映射

## 文档目的

本文件定义 Common Design 中页面语义到 idux 标准组件的映射与调用约束，用于指导 AI Coding 准确选择组件、调用组件能力并保持页面样式一致。

本文件只定义：

- 页面语义对应的首选组件；
- Coding 时命中组件的触发条件；
- 关键调用、样式、组合与状态要求；
- 禁止采用的替代实现方式。

本文件不负责判断：

- 当前产品是否已有业务封装组件；
- 是否应复用已有页面或业务模块；
- 当前代码仓库中具体组件路径、版本或完整 API；
- 页面最终采用直接引用、组件复用、复用框架还是全新开发。

上述内容由 `prd-design-code` 结合 Product Design 和当前代码环境决定。

## 调用边界

- 本表用于确定组件选型和项目内统一调用规则，不替代当前仓库 idux 版本的类型声明与组件文档。
- 生成代码前，优先复用仓库中已有的业务封装组件；没有对应封装时，再按本表调用 idux 标准组件。
- 本表未声明的 Props、事件和插槽不得凭空假设；应检查当前仓库中的同类实现或组件类型定义。
- 表内“适用场景”均表示 Coding 触发条件：页面描述或设计说明出现相应结构时，应优先命中对应组件。
- 表内“禁止做法”均表示实现禁区，重点避免原生元素替代、手写重复逻辑和自定义样式复刻组件。

## 组件映射表

| 设计语义 | 组件名称 | 适用场景 | 使用要求 | 禁止做法 |
|---|---|---|---|---|
| 按钮 | `IxButton` | 页面描述中出现新增、保存、取消、查询、重置、导入、导出、删除、确认等可点击操作时，统一使用。 | 默认使用 `size="sm"`；页面、弹窗、抽屉底部操作区使用 `size="md"`；唯一主操作使用 `mode="primary"`，常规操作使用 `mode="default"`。异步操作必须绑定 loading 状态并阻止重复提交；同组按钮按次要操作在前、主操作在后排列。 | 不要使用原生 `button`、可点击 `div` 或自定义 CSS 模拟按钮；不要在同一区域混用不一致的按钮尺寸或主次规则；同一组禁止多个主按钮；不要遗漏异步操作的 loading 和重复点击保护。 |
| 弹窗/对话框 | `IxModal` | 页面需要展示确认、提示、告警、结果反馈，或承载非表单型的轻量内容浮层时使用。 | 确认与提示类操作使用 `confirm`、`info`、`success`、`warning`、`error` 等标准能力，并明确标题、正文、确认/取消回调。功能弹窗必须配置标题、可见状态、关闭回调和底部操作；承载表格时可使用 `paddingless="vertical"` 并在内容区组合工具栏与 `IxTable`。完整新增编辑表单优先改用 `IxProFormModal`。 | 不要用自定义遮罩、绝对定位容器或第三方浮层替代 `IxModal`；不要用 `IxModal` 手工拼装完整表单流程；不要遗漏确认后的 loading、关闭、数据刷新或回写；不要将复杂多步骤流程塞入普通弹窗。 |
| 抽屉 | `IxDrawer` | 页面要求在保留当前页面上下文的前提下打开详情、辅助配置或轻量编辑面板时使用。 | 明确 `visible`、标题、打开入口、方向、宽度、关闭回调和 footer 操作；关闭后保持来源页筛选、分页和滚动等已有状态。普通内容、详情和轻量表单使用 `IxDrawer`；需要表单加载、校验和提交编排时优先使用 `IxProFormDrawer`。 | 不要用自定义侧滑容器替代 `IxDrawer`；不要在普通 `IxDrawer` 内重复实现完整表单容器逻辑；抽屉嵌套最多两层，禁止第三层；不要遗漏未保存提醒、提交后回写或列表刷新。 |
| 标签页 | `IxTabs` | 页面描述中出现视图切换、同层级内容切换或通过选项卡切换筛选维度时使用。 | 导航型 Tabs 使用 `type="line"`；作为筛选器时使用 `type="segment"`；默认 `size="md"`。绑定受控激活值和切换事件；切换后明确内容刷新、筛选重置或状态保留规则。 | 不要自行实现标签页样式；不要用普通按钮组替代 Tabs；不要在导航型与筛选型场景混用错误的 `type`；不要只切换视觉状态而未同步内容数据。 |
| 标签 | `IxTag` / `IxTagGroup` | 表格、详情、列表或表单回显中需要展示分类、状态、属性标记、等级标识、可移除条目或多个关联标签时使用。 | 状态类标签必须通过 `status` 使用组件预设语义色，并保持同一业务状态在全局的文案与状态映射一致；需要突出状态、风险等级或分类时使用 `filled`，边框型样式使用 `bordered`，不得手写颜色与边框。需要风险、告警、来源等图形语义时使用 `icon` 属性或 `#icon` 插槽；安全等级、风险等级、优先级等数字前缀使用 `number`，可与 `filled` 组合。可移除标签使用 `closable` 并处理 `close` 事件，同步更新表单值、筛选条件或数据源。多个关联标签使用 `IxTagGroup` 管理；组合标签设置 `gap="0"`，标签过多时通过 `maxCount` 省略，并用 `#rest`、`restRender` 配合 `IxPopover` 展示完整列表。仅对低风险、可逆的标记切换使用可变更标签，变更后同步数据并处理失败回滚。 | 不要用普通文本加自定义背景、边框或颜色模拟标签；不要在同一状态上混用不同的 `status`、颜色或文案；不要用多个 `IxTag` 加自定义 margin、负边距拼接组合标签；不要让过多标签无限换行撑高表格行；不要为只读状态增加 `closable`；不要将下线、删除、权限变更、策略生效等高影响操作设计为可变更标签。 |
| 文本 | `IxText` | 定宽区域内展示可能溢出的名称、地址、规则、说明或多行文本，或需要提供纯文本复制能力时使用。 | 长文本使用 `ellipsis` 自动省略；多行文本通过 `<br />` 分行，并配合 `ellipsis.rows` 控制最大显示行数。需要展开查看完整内容时使用 `ellipsis.expandable`；需要复制时使用组件复制能力，复制内容必须是纯文本，并按需要配置 `trim` 控制是否清除多余空格和换行。 | 不要用 CSS 手写省略逻辑替代组件能力；不要让长文本撑破表格列、操作区或表单布局；不要把富文本或复杂节点作为复制内容；不要以截断文本作为唯一的信息访问方式。 |
| 单选框 | `IxRadio` / `IxRadioGroup` | 表单或筛选条件中出现一组选项互斥选择，如状态、动作、模式、类型等单选值时使用。 | 单个选项使用 `IxRadio`，一组互斥选项必须配合 `IxRadioGroup` 管理选中值。需要按钮样式时在 `IxRadioGroup` 上使用 `buttoned`；按钮样式尺寸使用 `size="sm"`、`size="md"`、`size="lg"`，默认 `md`，且仅在 `buttoned` 为 true 时生效。选项下方需要联动附加内容时使用 `fieldset` 插槽，并可通过 `showFieldsetArrow` 控制展开箭头。 | 不要用多个按钮、标签或普通文本模拟单选；不要让互斥选项脱离 `IxRadioGroup` 独立管理；不要在非 `buttoned` 场景强行配置按钮尺寸；不要把复杂多字段联动手写在组外而不跟随选中值切换。 |
| 选择器 | `IxSelect` | 表单、搜索或筛选中需要从候选项选择单个或多个值，或需要允许用户自由输入并回填为选项时使用。 | 单选默认使用 `IxSelect`；多选使用 `multiple`。多选需要确认后生效时使用 `needConfirm`；需要自由输入时使用 `allowInput`，单选可直接输入任意值，多选输入内容回填为新标签；需要校验搜索输入时使用 `searchValidator`。尺寸使用 `size="sm"`、`size="md"`、`size="lg"`，默认 `md`；可展开分组使用 `type: 'expandableGroup'`；需要扩展下拉菜单内容时使用 `overlayRender`。 | 不要用普通输入框或自定义下拉模拟选择器；不要用多个复选框替代复杂多选选择器；不要在需要确认的多选场景遗漏 `needConfirm`；不要在自由输入场景遗漏输入校验；不要手写分组展开收起或自定义下拉层逻辑替代组件能力。 |
| 分页 | `IxPagination` | 数据列表、表格或可分页的搜索结果需要切换页码、页大小或定位当前页时使用。 | 绑定当前页、页大小、总数及其变更事件；页码或页大小变更后重新请求数据。筛选条件变化时重置到第一页；请求期间保持分页与数据的 loading 状态一致。 | 不要手写页码按钮或用普通按钮组模拟分页；不要只更新页码而不刷新数据；不要在筛选变更后保留可能失效的高页码；不要遗漏总数和空结果处理。 |
| 进度条 | `IxProgress` | 表格、卡片、任务详情或上传流程中需要展示完成率、使用率、容量占比、任务进度或异常进度状态时使用。 | 线性进度条默认使用 `IxProgress`；进行中使用 `status="active"`，完成态使用 `percent=100`，异常态使用 `status="exception"`。需要在文字后追加图标或自定义说明时使用 `#format` 插槽；需要按区间变色时使用 `strokeColor`。环形进度使用 `type="circle"`；卡片内微型状态指示使用较小 `stroke-width` 并配合 `hide-info`。尺寸使用 `size="sm"`、`size="md"`、`size="lg"`。 | 不要用自定义 div、宽度动画或硬编码色块模拟进度条；不要只展示百分比而遗漏状态语义；不要在表格或卡片内使用过大的进度条撑破布局；不要手写中心文字或尾随图标替代 `#format`。 |
| 气泡确认框 | `IxPopconfirm` | 删除、停用、移除、重置等轻量确认操作需要在当前点击元素附近完成二次确认时使用。 | 由触发元素点击后弹出气泡式确认框；通过 `placement` 设置弹出方向，默认优先右上或右下。需要在确认框中嵌入表单控件或补充输入内容时使用 `#content` 插槽；确认、取消回调必须与触发操作绑定。 | 不要为轻量确认操作打开完整 `IxModal`；不要手写浮层和按钮模拟确认框；不要遗漏取消回调、确认 loading 或危险操作的明确文案；不要把复杂多步骤流程塞入气泡确认框。 |
| 步骤条 | `IxStepper` | 页面描述中出现明确的多步骤配置、逐步填写、进度导航或流程状态展示时使用。 | 绑定当前步骤与步骤状态；步骤名称、顺序和可回退规则必须与表单或流程数据一致。仅展示流程时使用 `IxStepper`；需要分步表单的数据校验、暂存和提交时优先使用 `IxProFormStepper`。 | 不要用文本、图标和自定义连线手写步骤条；不要允许跳过未完成且必须校验的步骤；不要让视觉步骤与实际提交数据或校验状态不一致。 |
| 复选框 | `IxCheckbox` | 页面要求多项选择、布尔开关式确认、表格批量选择或全选/反选时使用。 | 单项绑定布尔值；多项选择绑定选中值集合；全选状态必须根据子项计算，并处理半选状态。禁用项不得被全选逻辑错误修改。 | 不要用原生 checkbox 或图标模拟勾选状态；不要仅修改视觉勾选而不同步受控值；不要遗漏全选、半选、禁用项和数据刷新后的选中状态清理。 |
| 日期选择 | `IxDatePicker` | 表单或筛选条件需要输入单个日期、日期时间或日期范围时使用。 | 根据字段含义选择单日、日期时间或范围模式；绑定受控值与格式化规则。范围选择必须校验开始时间不晚于结束时间；筛选提交值应与接口所需格式一致。 | 不要使用普通输入框手填日期格式；不要自行拼接两个输入框模拟日期范围；不要只限制 UI 而遗漏提交前的范围和格式校验。 |
| 表单 | `IxProForm` | 页面、弹窗或抽屉中存在多个字段录入、校验、重置和提交的统一流程时默认使用。 | 默认使用 `IxProForm` 管理字段、初始值、必填与格式校验；提交前执行统一校验，重置、回填和字段联动通过组件能力实现。弹窗和抽屉中的表单分别使用 `IxProFormModal`、`IxProFormDrawer`，不降级为基础表单手工组合。 | 不要用零散 state 和独立输入控件手写完整表单校验；不要用 `IxForm` 手工拼装常规表单流程；不要绕过表单校验直接提交；不要只在接口报错后才显示字段错误；不要在同一表单混用无规则的控件尺寸和标签布局。 |
| 基础输入框 | `IxInput` | 表单字段、搜索栏或独立筛选条件需要输入单行文本、名称、地址、关键字等值时使用。 | 默认使用 `size="md"`；表单字段通过 `IxProForm` 绑定，筛选输入绑定受控值与查询事件。固定前后格式使用 `addonBefore`、`addonAfter` 或组件原生能力实现，例如协议、单位、域名前缀或端口说明。 | 不要自行拼接前后缀样式；不要用多个零散文本和输入框模拟固定格式；不要使用原生 `input` 替代；不要在同一表单混用不一致的输入框尺寸。 |
| 数字输入框 | `IxInputNumber` | 表单字段或筛选条件需要录入数量、端口、阈值、优先级数值、时长或比例等数值时使用。 | 使用 `IxInputNumber` 承载数值输入；配置最小值、最大值、步长和精度。固定前后格式或数值单位通过 `addonBefore`、`addonAfter` 实现，不手工拼接输入框样式；接口值保持数值类型。 | 不要用 `IxInput` 或原生输入框代替需要数值约束的字段；不要用多个文本节点和输入框模拟固定前后缀；不要将数值作为未经转换的字符串提交。 |
| 表格 | `IxProTable` | 页面描述中出现同类对象列表、字段列、行操作、分页、批量操作或管理型数据视图时默认使用。 | 默认使用 `IxProTable` 承载表格、查询、列配置、分页和批量操作。首列优先放对象主标识，操作列固定在末列；状态字段使用 `IxTag`、Badge、状态点或项目既有状态组件。字段较多时仅保留核心字段，次要信息进入详情、抽屉、展开行或列设置；筛选项超过 4 个时搭配 `IxProSearch`。必须补齐 loading、空态、异常态和分页。 | 不要用 `IxTable`、原生 `table` 或 `div` 列表替代默认的 `IxProTable`；不要用表格展示单个对象详情，详情应使用 `IxProDesc`；不要在单元格内随意使用硬编码颜色表达状态；不要遗漏空态、异常态、分页或批量选择状态。 |
| 高级搜索 | `IxProSearch` | 单页存在超过 4 个筛选字段，或需要筛选字段选择、条件联动、常用条件收藏等能力时使用。 | 明确可选筛选字段、字段类型、默认条件、字段联动、查询/重置行为和提交参数结构；查询后重置分页到第一页。需要收藏能力时同步定义收藏条件的保存、加载和应用逻辑。 | 不要将超过 4 个筛选项平铺为普通控件；不要用多个零散输入框或自定义筛选面板替代；不要遗漏已定义的字段联动、重置、分页重置或收藏条件行为。 |
| 描述列表 | `IxProDesc` | 详情页、抽屉详情、日志详情或只读字段展示需要按“字段名-字段值”呈现时使用。 | 字段较少时使用单列；信息较多时根据容器宽度使用 2 列或 3 列。按业务主题增加小标题分组，并明确字段归属；长值按 `IxText` 的省略与查看完整内容规则处理。 | 不要将大量详情字段无分组连续堆叠；不要脱离容器宽度固定使用多列；不要用表格替代以字段名-字段值为主的详情；不要自行用 `div` 拼装描述布局。 |
| 表单弹窗 | `IxProFormModal` | 新增、编辑、复制、配置等需要在弹窗内完成字段加载、录入、校验与提交的短流程表单时使用。 | 配置标题、打开入口、可见状态、初始值、表单字段、校验规则、提交回调和关闭回调；编辑态先加载详情并回填。底部按钮遵循 `IxButton` 主次规则；表单内容较长时改用 `IxProFormDrawer` 或独立页面。必须处理初始化 loading、提交 loading、成功关闭和来源数据刷新。 | 不要用普通 `IxModal` 手工拼接完整表单流程；不要遗漏加载态、提交态、取消关闭、未保存提醒或成功后刷新；不要在弹窗内承载多步骤或复杂长表单。 |
| 表单抽屉 | `IxProFormDrawer` | 新增、编辑、配置、关联等需要保留列表或详情上下文，且字段量或分组复杂度高于弹窗表单时使用。 | 配置标题、触发入口、可见状态、表单分组、字段校验、初始值、提交和关闭回调；字段较多时按业务主题分组。编辑态加载与回填、提交成功后的列表刷新或详情回写必须纳入组件流程。 | 不要用普通 `IxDrawer` 重复实现表单加载、校验、提交和关闭逻辑；不要把极短确认操作放入表单抽屉；不要遗漏未保存提醒；不要在抽屉内继续堆叠复杂抽屉流程。 |
| 分步表单 | `IxProFormStepper` | 多个字段组存在先后依赖，且需要逐步校验、暂存、回退与最终确认提交时使用。 | 明确步骤名称、每步字段、前后依赖、校验触发时机和上一步/下一步/提交按钮规则；步骤数据需要暂存，回退后必须保留已输入值；最终提交前校验全部必要步骤。 | 不要用普通步骤条加多个零散表单手工拼接；不要把无步骤依赖的普通表单强行拆分；不要遗漏跨步骤校验、回退保留或最终提交校验。 |
| 动态表单列表 | `IxProFormList` | 表单内需要动态新增、删除、排序或批量配置同结构字段组，如规则条件、关联对象、参数组或通知接收人时使用。 | 明确列表项字段结构、默认行、最少/最多项、删除条件、空列表处理、行内校验和排序规则。新增、删除、排序后同步表单值；提交数据结构必须与接口格式一致。 | 不要用手写数组渲染替代组件能力；不要遗漏最少一项、最多项、删除确认、重复项校验或行内错误提示；不要允许动态列表无限制增长。 |
