# 标签形态与使用

用于确定「标签」在不同语义下采用哪种形态、颜色与交互方式。组件能力与禁忌以 [idux 组件映射表](../../05-components/idux-component-map.md) 中的 `IxTag` / `IxTagGroup` 行为准，本文不重复组件能力描述；表格列的字段映射见 [表格与数据管理](../02-solution-patterns/table-patterns.md) 第 7.2 节。

## 1. 形态清单

| 形态 ID | 名称 | 适用语义 | 结构与要点 |
| --- | --- | --- | --- |
| `tag-switchable` | 可变更标签 | 可在行内直接切换的低风险状态，如启用/禁用、是否生效 | 图标 + 正文文字 + 下拉 icon；点击下拉 icon 展开选择面板；切换后同步数据并处理失败回滚 |
| `tag-status-dot` | 点状标签 | 设备、服务器、节点的运行状态 | 彩色圆点 + 正文文字；绿圆点在线、灰圆点离线、橙圆点告警 |
| `tag-status-icon` | icon 标签 | 有阶段推进语义的任务、流程、处置状态 | icon + 正文文字，如待开始、进行中、已完成、已结束、失败 |
| `tag-level` | 深色标签 | 风险高低、等级、严重程度、数据分级 | 彩色背景 + 白色文字 |
| `tag-semantic` | 浅色标签 | 类型化的安全语义，如攻击类型、威胁类型、检测命中 | 淡色背景 + 同色系深色文字 |
| `tag-plain` | 浅灰标签 | 无明显风险倾向的非核心分类、来源、协议、区域 | 中性浅灰；同组仅两种类型且需要区分时可用绿、蓝浅色标签 |
| `tag-group` | 标签组 | 一个字段对应多个标签 | 使用 `IxTagGroup`；超过 `maxCount` 折叠为「+N」，悬浮展示完整列表 |

## 2. 形态选择判定链

按顺序判断，命中即止。

| 顺序 | 判断条件 | 结论 |
| --- | --- | --- |
| 1 | 字段表达「状态」 | 进入第 2-4 步选择状态类形态 |
| 2 | 状态可在行内直接切换，且低风险、可逆 | `tag-switchable` |
| 3 | 状态是设备、节点、服务的运行态（在线、离线、告警） | `tag-status-dot` |
| 4 | 状态有阶段推进语义（任务、流程、处置） | `tag-status-icon` |
| 5 | 字段不是状态，而是等级、风险、严重性、分级 | `tag-level` |
| 6 | 字段是类型化安全语义（攻击、威胁、命中） | `tag-semantic` |
| 7 | 字段是一般分类、来源、协议、区域 | `tag-plain` |
| 8 | 一个字段对应多个标签 | 叠加 `tag-group` 承载（形态按第 2-7 步确定） |

判定说明：

- 状态类与分类类的分界线是「是否表达可用性、健康度或推进阶段」：是则走状态类，否则走分类类。
- 可变更标签只用于低风险、可逆的状态切换；下线、删除、权限变更、策略生效等高影响操作不得设计为可变更标签。
- 同一业务状态的文案与颜色必须在全局一致，不得在不同页面用不同颜色表达同一状态。
- 一个字段只能选一种状态形态，禁止同一状态同时出现圆点、图标与颜色三重表达。
- 标签只承载识别与状态信息，不承载说明文案；需要解释时使用字段说明或悬浮提示。

## 3. 场景取值

| 场景 | 取值方式 |
| --- | --- |
| 表格单元格 | 按 [表格与数据管理](../02-solution-patterns/table-patterns.md) 7.2 的字段到形态映射取值，并遵守 7.2.3 的标签配额 |
| 详情与描述列表 | 字段值用标签回显，不受表格配额限制，但同一详情内保持形态克制，同类信息不混用多种形态 |
| 表单编辑态 | 选择使用 `IxSelect`（允许新建时使用 `allowInput`）；只有只读回显才使用标签 |
| 筛选区 | 筛选项使用 `IxSelect` 或标签筛选控件，不用标签组充当筛选器 |
| 卡片与统计区 | 状态强调使用状态类标签；分类信息优先使用浅灰标签或文本 |

## 4. 输出与自检

输出字段展示方案时，写明字段名、形态 ID、颜色语义与交互行为（是否可切换、折叠规则）。

自检清单：

- 形态唯一：同一字段只选一种形态，未叠加多种状态表达。
- 状态语义正确：状态类使用组件预设语义色与全局统一的状态映射，未手写颜色。
- 可切换边界：仅低风险、可逆状态使用可变更标签，且已说明失败回滚。
- 多值处理：多标签使用 `IxTagGroup`，并定义折叠阈值与完整查看方式。
- 配额（表格场景）：遵守同一表格内标签总数与各形态出现次数的限制。
